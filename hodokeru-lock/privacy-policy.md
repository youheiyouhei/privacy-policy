# ほどけるロック プライバシーポリシー

最終更新日：2026年11月11日

このプライバシーポリシーは、iPhoneアプリ「ほどけるロック」（以下「本アプリ」）が、利用者の情報をどのように扱うかを説明するものです。

## 1. アプリの提供者

- 提供者：Yohei Kajiro
- アプリ名：ほどけるロック
- 連絡先：「7. お問い合わせ」をご覧ください

## 2. 本アプリが扱う情報と、その取得方法

本アプリが扱う情報は、次のとおりです。これらはすべて、利用者のiPhoneの中にだけ保存されます。

| 情報 | 取得方法 |
| --- | --- |
| プロファイルの名前 | 利用者が入力します |
| ロックするアプリ・カテゴリ・Webサイトの選択 | 利用者がiOSのスクリーンタイムの画面で選びます。本アプリは、iOSが発行する識別子として保存します |
| ロックの記録（始めた時刻、終了予定の時刻、終わった時刻、使ったプロファイルの名前、途中で外す方法、終わり方） | 本アプリが自動で記録します |
| 「5分だけ使う」でロックを一時的に外した時刻と、戻す予定の時刻 | 本アプリが自動で記録します |
| 解除用のQRカードの内容（ランダムな文字列） | 本アプリが端末の中で自動で作ります |

途中でロックを外すとき、解除用のQRカードを読み取るためにカメラを使います。読み取った文字列を照合するだけで、カメラの映像や写真は保存しません。

## 3. 利用目的

2の情報は、本アプリの機能を提供するためにだけ使います。

- 選んだアプリやWebサイトをロックし、決めた時刻に外す
- ロックの記録と、終わり方ごとの回数を表示する
- 決めた方法（QRカードの読み取り）で途中でロックを外せるかを確かめる

広告の表示、マーケティング、利用状況の分析には使いません。

## 4. 外部への送信、第三者への提供、情報収集モジュール

本アプリは、インターネットへの通信を行いません。2の情報を、提供者や第三者に送信することはありません。

本アプリには、広告や利用状況の分析などのために情報を集めるモジュール（他社のSDKなど）は組み込まれていません。

## 5. 保存期間と削除

2の情報は、本アプリが端末に入っている間、端末の中に保存されます。

- プロファイルは、本アプリの「プロファイル」画面で削除できます
- 解除用のQRカードは、本アプリの「設定」画面で作り直せます（作り直すと、前のカードは使えなくなります）
- 本アプリを端末から削除すると、本アプリが保存した情報もすべて削除されます

提供者は2の情報を受け取っていないため、提供者が利用者の情報を保存したり削除したりすることはありません。

## 6. 許可の取得と、利用者が選べること

本アプリは、次のiOSの機能を、利用者の許可を得てから使います。許可は、iOSが表示する確認画面で求めます。

| 機能 | 使う目的 | 許可しない場合 |
| --- | --- | --- |
| スクリーンタイム | 選んだアプリやWebサイトをロックするため | ロックを使えません |
| カメラ | 解除用のQRカードを読み取るため | 「QRを読む」でロックを外せません（緊急解除はできます） |
| 通知 | ロックが予定通りに外れたことを知らせるため | 通知が届きません（ロックは予定通りに外れます） |

許可は、iOSの「設定」アプリで、いつでも取り消せます。
